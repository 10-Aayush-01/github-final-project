\# GitHub Final Project



This project is a simple interest calculator.



\## Description



The calculator calculates simple interest using the principal amount, annual rate of interest, and time period.



\## Formula



Simple Interest = (Principal × Rate × Time) / 100



\## Input



\- `p`: Principal amount

\- `r`: Annual rate of interest

\- `t`: Time period in years



\## Output



The calculated simple interest.
